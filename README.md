# 📊 Генератор сетки таблиц со скриншотом

Веб-приложение на Node.js для создания настраиваемых таблиц с буквами кириллицы, редактированием стилей в реальном времени и экспортом в PNG.

## ✨ Возможности

- 🔤 Генерация таблицы в формате Excel (А1, А2, А3, Б1, Б2, Б3...)
  - Настройка диапазона букв для колонок (например, от А до Я)
  - Настройка диапазона чисел для строк (например, от 1 до 100)
- 🎨 Редактирование стилей в реальном времени:
  - Размер и цвет текста
  - **Жирный шрифт** для ячеек и заголовков
  - **Обводка текста** (цвет и толщина) для лучшей читаемости
  - Цвет фона ячеек и заголовков
  - **Прозрачность** фона таблицы, ячеек и заголовков (0-100%)
  - Границы ячеек (цвет и толщина)
  - Размеры ячеек
  - Шрифт
  - Отступы
- ✏️ **Редактируемая угловая ячейка**
  - Кастомный текст в левом верхнем углу
  - Индивидуальные настройки шрифта и размера
- 🖼️ **Импорт и размещение изображений**
  - Загрузка множества изображений
  - Перемещение изображений мышкой по таблице
  - Изменение размера изображений
  - Изображения сохраняются в скриншоте
- 🔍 **Масштабирование (Zoom)** таблицы от 10% до 200%
  - Удобный просмотр больших таблиц
  - Плавное изменение масштаба
  - **Зум колесиком мыши** - крутите колесико для увеличения/уменьшения
  - **Drag-to-Pan** - перемещение мышью при зуме
- 📷 Создание скриншота таблицы в формате PNG
  - **Прозрачный фон PNG** - возможность сохранить с альфа-каналом
  - Высокое качество (2x scale)
  - Мгновенное скачивание
- 💾 Сохранение конфигурации для повторного использования
- 📱 Адаптивный интерфейс

## 🚀 Установка и запуск

1. Установите зависимости:
```bash
npm install
```

2. Запустите сервер:
```bash
npm start
```

3. Откройте браузер и перейдите по адресу:
```
http://localhost:3001
```

## 📝 Использование

1. **Настройка таблицы:**
   - Укажите начальную и конечную буквы (колонки): например, от А до Д
   - Укажите начальное и конечное число (строки): например, от 1 до 10
   - Настройте размеры ячеек
   - Таблица будет содержать ячейки: А1, А2, ..., Б1, Б2, ..., В1, В2, и т.д.

2. **Стилизация:**
   - Измените цвета, шрифты и размеры
   - Все изменения применяются в реальном времени

3. **Создание скриншота:**
   - Включите/выключите опцию "Прозрачный фон PNG"
   - Нажмите кнопку "📷 Скриншот PNG"
   - Файл автоматически скачается с прозрачным фоном (если опция включена)

4. **Сохранение настроек:**
   - Нажмите "💾 Сохранить конфиг"
   - Настройки сохранятся в `config.json`

## ⚙️ Конфигурация

Файл `config.json` содержит все настройки таблицы и стилей. Вы можете редактировать его вручную или через веб-интерфейс.

## 🛠️ Технологии

- **Backend:** Node.js, Express
- **Frontend:** HTML5, CSS3, JavaScript
- **Скриншоты:** html2canvas
- **Конфигурация:** JSON
